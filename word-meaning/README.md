# Word Meaning

会話の Claude の回答で語を選ぶと、選んだ範囲の下に「意味を調べる」を出す。押すと、その語の意味を、前後の文に合わせて一言で出す。意味は、working server の Claude Code に、プラグインの設定のモデル（既定は Haiku）で聞く。

```
│ この処理は冪等なので、二度呼んでも同じです。      │
│           ‾‾‾‾                                    │
│         ┌──────────────────────────────────────┐ │
│         │ 冪等                                 │ │
│         │ 同じ操作を何度繰り返しても、結果が   │ │
│         │ 最初の 1 回と同じになる性質のこと。  │ │
│         └──────────────────────────────────────┘ │
```

## 出すとき

- 回答の文を選んだとき（P22、`answerSelection`）に、Gasho が選んだ範囲の下に出す枠の中に出す。出すのは Claude の回答の本文で選んだときだけで、利用者の発言とツールの結果では出さない（Gasho が決める）
- 選んだ文字列が 40 字までで、改行を含まないときだけ出す。working server がつながっていて、daemon の部分を使えるときだけ出す
- 初めは「意味を調べる」のボタンだけを出す。押すと daemon の部分に聞き、答えを待つあいだは「意味を調べています…」を出す。答えが来たら、語とその意味を出す
- 調べられなかったときは、理由と「もう一度」を出す
- 同じ語を同じ文の中でもう一度選ぶと、ページを開いているあいだは、前の答えをすぐに出す（`useRequest` が覚えている答え。24 時間まで）
- 選択を外す・Esc・枠の外を押すと消える（Gasho が消す）

## 意味の調べ方（daemon の部分）

1. 画面の部分は、選んだ語と、回答の本文の語の前と後を、それぞれ 4000 字まで（設定の `contextChars` の上限）送る。回答の本文は、Gasho が渡す画面に出ている文字で、Markdown の記号は入らない
2. daemon の部分は、語と前後を合わせて設定の `contextChars` の文字数（既定は 600 字）になるよう、前と後を半分ずつ切り出す。片方が足りなければ、もう片方を多く取る。絵文字のサロゲートペアの途中では切らない
3. 前後の文の中で語を `<selected>` で囲み、切ったところに「…」を付けて、Claude Code に、その文での語の意味を、文と同じ言語の一文で頼む
4. Claude Code は、プラグインのフォルダー（`ctx.dataDir`）の中で、`-p --output-format json --effort low` と、短い system prompt、ツール・フック・MCP サーバー・スキル・セッションの保存なしで動かす。gasho-daemon はこのフォルダーの Claude Code をセッションとして扱わないので、Gasho のセッションの一覧には出ない（API 1.4）
5. 答えの `result` を 1 行にして返す。300 字より長ければ切る

Claude Code は 50 秒まで待つ。過ぎたとき、Claude Code が見つからないとき（gasho-daemon の `GASHO_CLAUDE_BIN`）、Claude Code が失敗したとき（標準エラーの 1 行目を添える）、答えが空のときは、それぞれの理由を画面に出す。

## 設定

| キー | 中身 |
|---|---|
| `model` | 意味を調べるモデル。`haiku`（既定）か `sonnet`。押すたびに Claude Code を 1 回動かすので、プランの使用量を使う。すべてのブラウザーで共通 |
| `contextChars` | Claude Code に渡す、語と前後の文を合わせた文字数。0〜4000、既定は 600。語より少ないときは語だけを渡す。すべてのブラウザーで共通 |

設定を変えると、次に調べたときから新しい値を使う。ページを開いているあいだに覚えた答えは、設定を変えてもそのまま出す。
