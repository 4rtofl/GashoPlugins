# Image Preview（image-preview）

セッションのファイルのパネルで画像を開くと、Gasho の表示の代わりに、拡大・縮小して見る表示を出す。← → キーと左右のボタンで、同じフォルダーの前と後の画像に移る。画像の下には、幅×高さ（px）と容量を出す。

プラグインの API 1.18 に対応した Gasho が要る（4rtofl/Gasho#282）。ファイルのパネルの表示を差し替える拡張点（`fileViewers`）を使う。画面の部分だけで、daemon の部分も権限も持たない。

## 決めたこと

1. 扱うのは、gasho-daemon が画像として送る PNG・JPEG・GIF・WebP・AVIF・BMP・ICO。拡張子の大文字と小文字は区別しない。SVG は、gasho-daemon が文字として送り、Gasho が見た目と文字を切り替えて編集もできるので、扱わない
2. 開いたときは、画像の全体が枠に収まる大きさで、枠の真ん中に出す。枠より小さい画像は、そのままの大きさで出す
3. 拡大は 3200% まで。縮小は、全体が収まる大きさまで
4. 300% 以上に拡大すると、画素をぼかさずに四角のまま出す（`image-rendering: pixelated`）。画素を 1 つずつ見分けられるようにするため
5. 前と後の画像は、同じフォルダーの画像だけを、ファイルの一覧と同じ順（フォルダーが先、そのあと名前の順）に並べて選ぶ。最初と最後で止まり、反対の端には移らない
6. ← → キーで移るのは、表示（枠と下の行）にフォーカスがあるときだけ。セッションの入力欄で文字を書いているときに、画像が変わらないようにするため。画像を開いたときに、ほかにフォーカスのあるものがなければ、表示にフォーカスを移す

## 画面

```
  shots / b.png                              ← Gasho のパンくず
  244 KB  更新 3 分前                         ← Gasho の容量と更新の行
┌────────────────────────────────────────┐
│                                        │
│ (‹)            画像               (›)  │  ← 枠の高さは画面の 70%
│                                        │
└────────────────────────────────────────┘
  1920 × 1080 px  244 KB  2 / 3        50%  [全体を表示]
```

- **拡大・縮小**: マウスのホイール（1 目盛りで約 13%）、トラックパッドのピンチ、タッチ画面の 2 本指のピンチ。ポインターのある点（ピンチでは 2 本の指の間の点）が、画像の同じ点の上に残るように拡大する。枠の上でホイールを回しても、パネルはスクロールしない
- **動かす**: ドラッグ（タッチ画面では 1 本指）。枠より大きくなった向きにだけ動き、画像の端が枠の端より内側に入るところまでは動かない。枠より小さい向きは、枠の真ん中に置く
- **全体を表示**: 全体が収まる大きさと位置に戻す。拡大も移動もしていないあいだは、パネルの幅が変わったときにも収め直す
- **前・後**: 枠の左右の端のボタンと ← → キー。同じフォルダーの画像が 1 枚だけのときと、Gasho がフォルダーの一覧をまだ読んでいないときは出さない。最初の画像では「前の画像」、最後の画像では「次の画像」を押せなくする
- **下の行**: 幅×高さ（画像を読み込んでから出す）、容量、同じフォルダーの画像の何枚目か、いまの倍率
- 5MB を超えて gasho-daemon が送らない画像は、そのことを枠の中に書く。その画像からも、← → と左右のボタンで前と後の画像に移れる。ブラウザーが読めない画像（壊れたファイルなど）も、そのことを書く
