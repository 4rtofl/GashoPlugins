# Session List Rewind（session-list-rewind）

サイドバーに、worktree の行の代わりに、セッションそのものを並べる。セッションは、リポジトリごとのカテゴリ（見出し）に分ける。サイドバーにセッションが並ぶので、セッション画面の上のタブからは、セッションのタブと「＋」を外す。

いまの Gasho のサイドバーは、worktree ごとに1行を出し、同じ worktree のセッションは上のタブで切り替える。同じ worktree で多くのセッションを動かすと、サイドバーの行は少ないままで、セッションはタブからしか選べない。このプラグインは、worktree の一覧より前の「セッション」の一覧のように、サイドバーからセッションを直接選べるようにする（Rewind）。

プラグインの API 1.7 に対応した Gasho が要る（Gasho の PR #48）。サイドバーのセッションの一覧（P17、`sessionList`）を使う。Gasho の [docs/plugins.md](https://github.com/4rtoflow/Gasho/blob/main/docs/plugins.md) に書いてある。

## 決めたこと

1. カテゴリは見出しで分ける（Discord のカテゴリの形）。見出しはリポジトリ名で、押すと畳める。見出しの右の「＋」で、そのリポジトリにセッションを起動する
2. カテゴリを出しているあいだ、セッション画面の上の行から、セッションのタブと「＋」をいつも隠す。過去の会話のボタンと、プラグインのタブ（github-almighty の Issue・PR など）は残す
3. カテゴリも、カテゴリの中のセッションも、最後に使った順に並べる。どちらもドラッグで並べ替えられ、並べ替えた順をブラウザーごとに覚える
4. 分け方と既定の順はこのプラグインが決め、描くのは Gasho である。並べ替えた順と畳んだ状態は Gasho が覚える。このプラグインは、daemon の部分も CSS も持たず、権限も要らない

## 画面

```
┌────────────────────────────┐
│ セッション          ▤ ↺ ＋ │  ▤：リポジトリを登録・解除…
│ ˅ GashoPlugins           ＋ │  ↺：最後に使った順に戻す（並べ替えたときだけ）
│   ● Session List Rewind…   │
│   ● usage-plugin の画面仕様 │
│ ˅ Gasho                  ＋ │
│   ● セッション画面の下方…  │
│     main                   │  2行目：カテゴリのセッションが2つ以上の
│   ● サイドバーの作り直し   │        worktree にまたがるときのブランチ名
│     feat/sidebar           │
│ › Bobert         確認 1  ＋ │  畳んだカテゴリ：確認待ちの数
└────────────────────────────┘
```

- 行は、Gasho の以前の「セッション」の一覧と同じく、状態の点、名前、確認・オフライン、バックグラウンドの作業のスピナーを出す。右クリック（スマホでは長押し）で、名前の変更・フォーク・削除のメニューを開く
- 畳んだカテゴリでも、開いているセッションの行は出す
- セッション画面の上の行には、過去の会話のボタンと、プラグインのタブだけが残る。セッションの無い worktree の画面には、本文に起動のボタンが出る
- アイコンだけのサイドバーでは、カテゴリは区切りの線に、畳んだカテゴリは1つのアイコンになる

## 分け方

- カテゴリは、working server とリポジトリのフォルダー（main の worktree のフォルダー）ごとに1つ。同じリポジトリの worktree のセッションは、1つのカテゴリにまとまる
- リポジトリの外のフォルダーのセッションは、フォルダーごとに1つのカテゴリにする。Gasho の worktree の一覧が、そうしたフォルダーを1行ずつにしているのと同じである
- 見出しはリポジトリ名（GitHub のリポジトリ名か、フォルダー名）。working server が2台以上あるときは、その名前を薄い字で添える。同じパスのリポジトリでも、working server が違えば別のカテゴリになる。ポインターを乗せると、working server とフォルダーを出す
- セッションの2行目には、カテゴリのセッションが2つ以上の worktree にまたがるときだけ、その worktree のブランチ名（HEAD が detached なら、フォルダー名）を出す。どれも同じ worktree なら出さない
- 見出しの「＋」は、リポジトリのフォルダー（main の worktree）で起動する。そのフォルダーがカテゴリの worktree に無いとき（bare のリポジトリなど）は、最後に使ったセッションの worktree で起動する。起動できなかったときは、Gasho がそのフォルダーを選んだ「新しいセッション」のダイアログを開き、理由や、フォルダーを信頼するかの確認を出す
- 登録したリポジトリでセッションの無いものは、見出しだけのカテゴリにする（「＋」で起動できる）。セッションが無くなってブラウザーが覚えている worktree は、出さない
- カテゴリの ID は「working server の ID ＋リポジトリのフォルダー」で、プラグインを更新しても変わらない。Gasho は、並べ替えた順と畳んだ状態を、この ID で覚える

## 並べ方

- セッションは、最後に使った順（最後の会話の記録の時刻、無ければ起動した時刻）。Gasho の worktree の一覧の「最後に使った順」と同じ時刻である
- カテゴリは、その中でいちばん最後に使ったセッションの順。セッションの無いカテゴリは、Gasho が渡した順（登録した順）で最後に並べる
- ドラッグで並べ替えると、Gasho がその順を覚えて、この順の上に当てる。並べ替えたあとに増えたカテゴリとセッションは先頭に出る。見出しの「最後に使った順に戻す」で戻す
- ポインターがサイドバーの一覧の上にあるあいだ（スマホではドロワーを開いているあいだ）は、Gasho が並びを止める。Claude が作業しているセッションは最後に使った時刻が変わり続け、押す前に行が動いてしまうためである

## 確かめたこと（2026-11-15）

Gasho の変更（API 1.7）の worktree から試しの Gasho サーバーを動かし、このプラグインと、worktree のタブを1つ足すだけの試しのプラグインを `plugin add --link` で入れて、ヘッドレスの Chrome（CDP）で確かめた。working server には、仮の gasho-daemon をつないだ。仮の gasho-daemon は、3つのリポジトリ（1つは worktree が2つ）、リポジトリの外のフォルダー、登録しただけのリポジトリのセッションを報告し、セッションの起動・削除に答える。

- カテゴリが最後に使った順に並び、2つの worktree にまたがる Gasho のカテゴリだけ、2行目にブランチ名が出た。確認待ちのバッジとバックグラウンドの作業のスピナーも出た
- セッション画面の上の行には、過去の会話のボタンと試しのプラグインのタブだけが残った
- 畳んだカテゴリに、確認待ちの数と、開いているセッションの行が出た。畳んだ状態は、読み込み直しても、プラグインの新しい版に入れ替わっても残った
- カテゴリ（1行のものも5行のものも）とセッションのドラッグ、Alt+↑、Esc、「最後に使った順に戻す」が動いた。5行のカテゴリの上で1行のカテゴリを12px ずつ止めても、並びは入れ替わり続けなかった
- ポインターを一覧に乗せたまま、仮の gasho-daemon でセッションを使ったことにすると、並びは変わらず、ポインターを離すと最後に使った順に変わった
- 見出しの「＋」で、セッションが起動して開いた。フォルダーを信頼するかを聞かれる場合は、そのフォルダーを選んだダイアログに、信頼の確認と Claude Code の注意が出た
- 行の右クリックのメニューから開いているセッションを削除すると、同じカテゴリの次の行が開いた
- 390px の幅では、ドロワーにカテゴリが並び、見出しと行にタッチ用のつまみが出た。畳んでもドロワーは閉じなかった
- プラグインを外すと、読み込み直さずに worktree の一覧とタブに戻った。フックがエラーを投げる版にすると、worktree の一覧とタブに戻り、一覧の見出しの下に知らせが、プラグインの画面に理由が出た
- ページを3回読み込み直し、ページの最初から見張っても、worktree の一覧とセッションのタブは一度も出なかった
- working server を2台にすると、同じパスの Gasho が、working server の名前の付いた2つのカテゴリに分かれた

## ファイルの構成とテスト

```
session-list-rewind/
├─ gasho-plugin.json       api 1.7、web だけ（daemon の部分も CSS も無い）
├─ package.json            build は gasho-plugin build、dev は gasho-plugin build --watch
├─ tsconfig.json
├─ src/web/
│  ├─ index.tsx            サイドバーのセッションの一覧（sessionList）。hideSessionTabs: true
│  └─ categories.ts        セッションをカテゴリに分け、既定の順に並べる
└─ test/
   └─ categories.test.ts
```

- `categories.test.ts`：同じリポジトリの worktree が1つのカテゴリにまとまること、カテゴリとセッションが最後に使った順になること、2行目のブランチ名の出し方、「＋」で起動する worktree の選び方（main の worktree、無ければ最後に使ったもの）、リポジトリの外はフォルダーごとになること、working server ごとに分かれて名前が付くこと、セッションの無い登録したリポジトリ、カテゴリの ID

## 今回は扱わないこと

- セッションを別のカテゴリへ動かすこと。カテゴリはリポジトリで決まる
- 分け方を設定で変えること（GitHub のリポジトリで working server をまたいでまとめる、ブランチごとに分ける、など）
- 前回の分け方を覚えて、プラグインの読み込み中に先に描くこと。いまは、読み込むまで一覧を空けて待つ
